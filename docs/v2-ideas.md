- vector database และ RAG pipeline เต็มรูปแบบ. บทที่ 16 สอนแค่การตัดสินใจและทำ
  retrieval เป็น tool ตัวหนึ่ง ถ้ามีคนขอบทเต็มจริงๆ ค่อยพิจารณา

  performance
