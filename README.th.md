# agentpath

เรียนรู้ว่า AI agent ทำงานอย่างไรจริง ๆ ด้วยการลงมือสร้างมันขึ้นมาเอง ตั้งแต่การเรียก
LLM เพียงครั้งเดียว ไปจนถึง agent harness ที่สมบูรณ์

## เหมาะกับใคร

คุณเขียนโปรแกรมได้บ้าง แต่ยังไม่เคยสร้างอะไรด้วย language model มาก่อน หรือเคยใช้ผ่าน
framework แล้วไม่เคยเข้าใจว่าข้างใต้มันทำอะไรอยู่ คุณไม่จำเป็นต้องรู้ machine learning เลย
และคอร์สนี้ไม่มีคณิตศาสตร์

## ทำไมถึงมีคอร์สนี้

มีบทเรียนมากมายที่พาคุณดู agent loop แต่เกือบทั้งหมดหยุดอยู่แค่นั้น เครื่องมือที่คนใช้งานจริง
ทุกวันอย่าง Claude Code และ OpenHands ไม่ใช่แค่ agent loop มันคือ harness ซึ่งหมายถึง
agent loop ที่ถูกห้อมล้อมด้วยการตรวจสอบสิทธิ์ การบันทึก session การจัดการ context การกู้คืน
จากข้อผิดพลาด และ protocol สำหรับ plugin แทบไม่มีใครสอนให้คุณสร้างส่วนนั้น

คอร์สนี้พาไปจนสุดทาง คุณเริ่มจากการส่ง HTTP request หนึ่งครั้งไปหา model และจบด้วย harness
ที่คุณเอาไปใช้งานได้จริง

ทุกบทยังมีฉบับภาษาไทยด้วย ซึ่งหาได้ยากมากสำหรับเนื้อหาที่ลงลึกขนาดนี้

## สิ่งที่คุณจะได้สร้าง

| ส่วน | เพิ่มอะไรเข้ามา | สถานะ |
|------|--------------|--------|
| 1 Foundations | agent ที่ทำ streaming ได้ เรียก tool ได้ วนลูปจนกว่างานจะเสร็จ และสลับ model provider ได้ | ใช้ได้แล้ว |
| 2 Real Tools | การอ่านและแก้ไขไฟล์ การรันคำสั่ง shell การค้นหาโค้ด และ coding agent ขนาดเล็กที่ใช้งานได้จริง | กำลังทำอยู่ |
| 3 The Harness | สิทธิ์การเข้าถึง การบันทึก session การจัดการ context การบริหาร token การทำ retrieval และการกู้คืนจากข้อผิดพลาด | มีแผนไว้ |
| 4 Advanced | MCP client, subagent, รูปแบบการทำงานแบบ multi agent, การทำ eval และการเลือก model | มีแผนไว้ |

## เริ่มต้นอย่างรวดเร็ว

ติดตั้ง uv ซึ่งเป็นตัวติดตั้ง Python และตัวจัดการ environment ที่คอร์สนี้ใช้

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

บน Windows ให้ใช้ PowerShell แทน

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

จากนั้น clone repository แล้วเปิดบทแรก

```bash
git clone https://github.com/YOUR-USERNAME/agentpath.git
cd agentpath
```

ตอนนี้ให้อ่าน [lessons/00-setup/README.md](lessons/00-setup/README.md) มันจะพาคุณเลือกว่าจะ
ให้ model ของคุณรันที่ไหน ซึ่งจะเป็นแบบฟรีและรันในเครื่องก็ได้ถ้าคุณต้องการ และตั้งค่า
environment variable สามตัวที่ใช้ตลอดทั้งคอร์ส

## การใช้ framework ฉบับสมบูรณ์

ทุกอย่างที่คอร์สนี้สร้างขึ้นถูกเผยแพร่เป็น package ด้วย คุณจึงติดตั้งฉบับสมบูรณ์แล้วอ่านเป็น
เอกสารอ้างอิงได้

```bash
pip install agentpath
```

```bash
export AGENTPATH_BASE_URL=http://localhost:11434/v1
export AGENTPATH_MODEL=qwen3
agentpath chat
```

## โครงสร้างของ repository นี้

`lessons/` เก็บโฟลเดอร์หนึ่งโฟลเดอร์ต่อหนึ่งบท แต่ละโฟลเดอร์อยู่ได้ด้วยตัวเอง คุณจึงเปิดบทไหน
ก็ได้แล้วรันโค้ดของมันโดยไม่ต้องทำบทอื่นมาก่อน โค้ดถูกทำซ้ำระหว่างบทอย่างตั้งใจ เพราะคอร์สที่
บทสี่แอบไปขึ้นอยู่กับการแก้ไขที่คุณทำในบทสอง คือคอร์สที่คนเลิกเรียนกลางคัน

`src/agentpath/` เก็บ framework ฉบับสมบูรณ์ ซึ่งก็คือแนวคิดเดียวกันที่เขียนไว้ครั้งเดียว
อย่างเรียบร้อย พร้อมชุดทดสอบ

`ci/` เก็บ model server จำลอง และสคริปต์ที่รันการตรวจสอบของทุกบท

`docs/` เก็บเอกสารออกแบบ แผนการพัฒนา และบันทึกเกี่ยวกับพฤติกรรมจริงของ provider แต่ละเจ้า

## การรันการตรวจสอบด้วยตัวเอง

ทุกบทมีไฟล์ check.py ที่พิสูจน์ว่าโค้ดที่คุณเขียนทำงานได้จริง คุณรันทั้งหมดพร้อมกันกับ model
server จำลองได้ ซึ่งไม่มีค่าใช้จ่ายและไม่ต้องใช้ API key

```bash
uv pip install -e ".[dev]"
python ci/run_lessons.py
```

นี่คือสคริปต์ตัวเดียวกับที่โปรเจกต์รันใน continuous integration ถ้ามันผ่านสำหรับคุณ มันก็ผ่าน
สำหรับทุกคน
