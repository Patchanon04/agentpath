# หนังสือ agentpath

หนังสือเล่มนี้อธิบายทฤษฎีที่อยู่เบื้องหลังบทเรียนทั้ง 24 บท และวิธีคิดเวลาจะเอาไปทำโปรเจกต์จริง

บทเรียนสอนให้คุณสร้าง หนังสือเล่มนี้อธิบายว่าทำไมมันถึงเป็นแบบนั้น ถ้าคุณอ่านบทเรียนแล้ว
ทำตามได้แต่ยังไม่แน่ใจว่าจะออกแบบของตัวเองยังไง เล่มนี้เขียนมาเพื่อคุณ

## หมายเหตุเรื่องคำศัพท์

ศัพท์เทคนิคคงไว้เป็นภาษาอังกฤษ และใส่ความหมายไทยในวงเล็บครั้งแรกที่พบในแต่ละบท
เหตุผลคือคุณต้องอ่านเอกสารภาษาอังกฤษต่อได้ การแปลศัพท์เป็นไทยทำให้ค้นหาต่อไม่เจอ
